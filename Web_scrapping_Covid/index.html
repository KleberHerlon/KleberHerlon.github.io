Web Scraping COVID-19 — Dados Globais da Pandemia

Extrai a tabela de casos por país da Wikipedia e estrutura em CSV — base limpa para análise temporal e geográfica.

Python 3.10+BeautifulSoup urllibCSV

O problema

Durante a pandemia, os dados oficiais de casos por país estavam espalhados em tabelas da Wikipedia — sem formato estruturado para consumo analítico. O objetivo era gerar um dataset CSV reutilizável para análises de evolução da doença.

Arquitetura do pipeline

🌐
Extract

urlopen na fonte pública + BeautifulSoup localiza a wikitable

🧹
Transform

Iteração por linhas/células (th/td) com get_text().strip()

💾
Load

Gravação em Dataset.csv (UTF-8) com o módulo csv

Destaque do código

# ETL clássico em funções reutilizáveis + docstrings
def fetch_wikitable() -> list:
    """Extract: localiza a tabela 'wikitable' na página da Wikipedia."""
    soup = BeautifulSoup(urlopen(DATA_URL), "html.parser")
    return soup.find_all("table", {"class": "wikitable"})[0].find_all("tr")

def rows_to_csv(rows: list, output_path: str = OUTPUT_CSV) -> None:
    """Transform/Load: itera as linhas HTML e grava o CSV (novo='' evita linhas em branco)."""
    with open(output_path, "wt+", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        for row in rows:
            cells = row.find_all(["td", "th"])
            writer.writerow([cell.get_text().strip() for cell in cells])
