Acompanhamento de carteiras offshore

Painel de controle de execução de ordens de manutenção por carteira: aderência de horas programadas, situação das OMs por estrutura e desempenho individual da equipe técnica — com filtros dinâmicos que recalculam todos os indicadores em tempo real.

🛡️
Dados 100% fictícios. Esta é uma demonstração técnica: todos os números, nomes de técnicos, chaves de embarque e identificadores são simulados e anonimizados. Mantivemos apenas a estrutura, a lógica de negócio e o modelo de dados originais. Nenhum dado real de operação, cliente ou colaborador é utilizado. Os arquivos de origem (.pbix) não são disponibilizados para download.

🧩 Stack técnica desta demonstração

Como este dashboard foi construído.
HTML5CSS3 (variáveis de design)JavaScript vanilla Chart.jsFiltros reativos client-sideAggregations em JS Paginação + sorting + buscaExport CSVResponsivo Base JSON anonimizada (LGPD)

O modelo original foi produzido em Power BI (Power Query / DAX, modelo estrela por carteira × técnico). Esta reimplementação web prova a lógica de negócio de forma independente de ferramenta: todos os indicadores são recalculados do zero a cada interação do usuário, sem servidor e em menos de 50 ms.
