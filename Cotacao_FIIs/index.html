Cotacao de FIIs — Pipeline ETL

Web scraping → normalização → Google Sheets. Ranking atualizado de fundos imobiliários brasileiros pronto para BI.

Python 3.10+Pandas (ETL) requestsgspreadGoogle Sheets API

O problema

Quem investe em FIIs precisa de um ranking consolidado e comparável — dividend yield, VPA, preço e vacância de todos os fundos em um só lugar. O recurso original entrega esses dados como texto misturado com R$, % e vírgulas, inviabilizando agregação direta.

Arquitetura do pipeline

🌐
Extract

requests + pandas.read_html no ranking do FundsExplorer

🧹
Transform

Limpeza de R$, % e separadores; conversão para float

☁️
Load

Gravação em Google Sheets (A1:Z400) via gspread

📊
Consumo

Power BI / Excel / Looker lêem diretamente a planilha

# ETL desacoplado: Extract → Transform → Load, com tipagem e tratamento HTTP
def fetch_ranking_frame() -> pd.DataFrame:
    """Extract: captura a tabela principal do ranking (com timeout e erro explícito)."""
    resp = requests.get(RANKING_URL,
                        headers={"User-Agent": USER_AGENT}, timeout=30)
    resp.raise_for_status()
    frames = pd.read_html(resp.text)
    if not frames:
        raise ValueError("Nenhuma tabela encontrada na p\u00e1gina.")
    return pd.DataFrame(frames[0])

def clean_frame(frame: pd.DataFrame) -> pd.DataFrame:
    """Transform: normaliza %, R$ e milhar para float (base analis\u00e1vel)."""
    df = frame.copy()
    for col in PERCENT_COLUMNS + CURRENCY_COLUMNS:
        if col in df.columns:
            df[col] = (df[col].astype(str)
                       .str.replace("%", "", regex=False)
                       .str.replace("R$", "", regex=False)
                       .str.replace(",", ".", regex=False)
                       .astype(float))
    return df.fillna(0)
